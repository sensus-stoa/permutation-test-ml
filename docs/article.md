## 2. Метод

Парный перестановочный тест:

1. Фиксируем разность метрик между моделями A и B.
2. Многократно переставляем предсказания между A и B по каждому объекту.
3. Строим эмпирическое распределение разности.
4. Считаем p-value как долю перестановок с разностью не меньше наблюдаемой.

## 3. Эксперименты

Результаты воспроизводятся командой:
