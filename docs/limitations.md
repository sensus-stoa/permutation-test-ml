# Ограничения метода

- **Вычислительная сложность.** O(N × M), где N — число перестановок,
  M — размер выборки. На больших выборках дорого.
- **Обмениваемость под H0.** Требует, чтобы при верной H0 предсказания
  моделей для каждого объекта были обмениваемы. Это разумное, но
  содержательное предположение.
- **Независимость наблюдений.** Объекты должны быть независимы;
  для сгруппированных данных (пациенты, временные ряды) нужна
  блочная перестановка.
- **Только точность сравнения.** Тест отвечает на вопрос «различаются ли»,
  а не «насколько велик эффект». Дополняйте его доверительными
  интервалами (например, bootstrap).
- **Дискретность p-value.** При малом N перестановок p-value грубо
  квантован; используйте не менее 10 000 перестановок для надёжности.
- **Множественные сравнения.** Если сравниваете много пар моделей,
  применяйте поправку (Bonferroni / Holm).
